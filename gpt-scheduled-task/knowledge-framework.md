# 财经日报分析框架（从学姐金融课提炼的公开方法摘要）

这是一份把本地 Obsidian 金融课笔记提炼成的通用分析规则，不包含原笔记全文、个人隐私或登录凭据。用于解释新闻和市场，不构成投资建议。

## 一、总流程：指标 → 模型 → 策略 → 工具 → 迭代

- 指标是信息输入：先记录来源、发布时间、数值或原话，区分官方数据、机构观点、媒体转述和市场传闻。
- 模型是判断框架：把数据放进经济周期、政策周期和资产传导链条，而不是只看一个新闻标题。
- 策略是条件推演：说明在什么条件下可能利好、利空或影响有限，同时写出反例和待验证点。
- 工具是执行载体：日报只做事实整理和情景分析，不给买入、卖出或仓位指令。
- 迭代是复盘：优先观察方向变化和拐点，定期用多项数据交叉验证，不能迷信单一指标。

## 二、宏观与周期

- 经济观察优先看 GDP、工业增加值、用电量、货运量、消费、就业和收入等，并用相互独立的数据交叉验证。
- 物价观察 CPI 与 PPI：CPI 更接近居民端，PPI 更接近生产端；不要根据单月数字直接下结论，要看连续方向。
- 企业景气观察 PMI：50 是扩张与收缩的分界线；连续上升或下降比单个月份更有参考价值。
- 资金与信用观察 M1、M2、社融、LPR、利率、债券收益率和财政政策。M1 更接近可立即使用的钱，M2 更接近总资金池；变化方向比静态绝对值更重要。
- 用复苏、过热、滞胀、衰退等周期语言描述环境，但要承认周期判断存在滞后和不确定性。
- 中国市场还要单独看政策周期：政策是托底、刺激、收紧还是引导资金流向，可能改变自然经济周期对资产的影响。

## 三、全球市场地图

先判断今天更接近风险偏好还是避险情绪，再解释局部资产。依次观察：

1. A 股、港股、美股和主要宽基指数是涨是跌。
2. 谁在领涨、谁在走弱，行业之间有没有共同逻辑。
3. 成交额、上涨下跌家数、涨停家数和资金流向，判断上涨是普遍共识还是少数板块的局部热闹。
4. 美元、美债收益率、黄金和大宗商品，帮助判断市场在交易利率、通胀、流动性还是避险。

指数涨跌本身不能代表市场全貌；要把指数、板块、市场广度和全球资产放在一张图里看。A 股、港股和美股的联动只能作为线索，不能直接当成因果证明。

## 四、资产传导和黄金分析

- 任何新闻都尽量写清楚传导链：事件或政策 → 利率/流动性/汇率 → 估值或盈利预期 → 行业和资产价格 → 风险偏好。
- 黄金主要是防守、避险和分散风险的资产，不能因为短期上涨就推断长期趋势。
- 黄金中长期重点观察美元真实收益率、美国名义利率、通胀预期、美元指数、央行购金和地缘冲突；实际利率和美元走强通常会形成压力，但每次都要用当日证据验证。
- 地缘冲突更可能先形成短期脉冲；是否变成长期趋势，要看冲突是否升级、通胀和利率是否同步变化。

## 五、A 股和行业新闻

- 把上涨或下跌拆成基本面、政策面、资金面、情绪面和技术面的可能贡献，不能把热搜或单一机构观点等同于基本面改善。
- 政策新闻要继续观察落地力度和时间；预期强但政策弱、政策强但盈利未跟上，市场反应可能与标题相反。
- 行业分析要回答“资金在交易什么”：景气改善、供给约束、价格变化、估值修复、政策催化还是情绪博弈。
- 技术指标只能辅助确认趋势和位置，不能代替宏观、政策、盈利和风险控制。
- 不因一条新闻推断整个大盘。若缺少指数、成交额或广度数据，明确写“数据不足，暂不判断”，不补造数字。

## 六、每条新闻的表达模板

每条新闻按以下顺序输出：信息性质、证据强度、发生了什么、为什么重要、可能的传导路径、可能影响的资产或行业、相反情景、下一步要验证什么。事实和推测分开写，机构观点必须标记为观点，原文链接必须保留。

## 七、日报末尾的大盘总结

最后必须单独写一节整体判断：

- 宏观环境：增长、物价、就业或政策信号目前偏向什么方向。
- 流动性与政策：利率、信用、财政和监管信号如何影响风险偏好。
- 大盘状态：A 股、港股、美股等可获得的宽基指数、市场广度、成交和领涨领跌方向。
- 全球联动：美元、美债、黄金等是否支持风险偏好或避险判断。
- 基准结论：用“偏强、偏弱、震荡、分化或数据不足”描述，并给出依据、反例和明日要验证的指标或事件。

如果当天没有足够的指数、成交或宏观数据，必须明确说明证据边界；整体总结可以是“暂不判断”，不能用一条新闻代替大盘分析。
